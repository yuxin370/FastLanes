# GALP Image ID 顺序实验结果（RTX 4090，2026-07-13）

## 结论

- 推理性能：连续 image ID batch 有显著收益。严格同样本配对下，吞吐从
  `148.908` 提升到 `1359.442 img/s`，中位加速 **9.13×**（repeat 范围
  `8.84–9.21×`）；相对当前全局随机 benchmark 的 `86.654 img/s`，实际迁移参考为
  **15.60×**（`15.35–15.83×`）。
- 推理精度：未发现显著影响。同一 measured cohort 的 1,280 张图片按 image ID
  对齐后，top-1 变化 `+0.078125` 个百分点、top-5 变化 `0`；只有 1 个 top-1
  correctness discordant pair，精确 McNemar `p=1.0`，低于预设 `0.5` 个百分点的
  实际显著阈值。
- 训练精度：3 seeds × 3 epochs 的短程 fine-tune 探针中，连续减打散的 held-out
  top-1 均值为 `+0.2604` 个百分点，配对 sign-flip `p=0.25`，未达到统计或实际
  显著阈值。这一探针不能代替完整 300-epoch ImageNet 重训。
- 训练风险：不能把“推理无显著影响”直接推广成“训练顺序无风险”。全量
  ImageNet train 路径顺序下，连续 batch 平均只有 `1.05` 个类别，`95.09%` 的
  batch 是单一类别；全局 shuffle 平均 `62.02` 个类别，单类 batch 为 `0%`。
  训练应采用连续物理读取加 shuffle buffer/随机逻辑顺序，不能直接用路径连续 batch
  替代随机 sampler。

## 实验条件

- GPU：NVIDIA GeForce RTX 4090，24,564 MiB；driver `590.48.01`。
- PyTorch `2.11.0+cu128`，CUDA runtime `12.8`，FP32。
- 模型：RGB-no-more JPEG-Ti ViT-Ti DCT checkpoint，SHA-256
  `bdbb1110b1d5383ab2774071834ee9597ceff85236b1ce212b2a0dc0af47c2cb`。
- 数据：ImageNet val GALP manifest，SHA-256
  `67a80a3d7b5f04dcf11cfb73cfc01cee1347f6bb2d070704d93ee93ff87fc0a4`。
- `seed=11997733`，`batch=64`，5 warmup batches，20 measured batches，5 repeats；
  正式汇总排除 repeat 0。
- GALP：cache 1,024 MiB，decode batch rowgroups 2，prefetch depth/workers 16/4，
  `rgbnomore-val-pushdown` 融合路径。

eligibility 严格沿用现 system benchmark 的原始 JPEG SOF 交集，共 48,615 张。GALP
metadata 单独判为 48,616 张，唯一差异是 image ID `49920`：原 JPEG 为 4 components，
GALP metadata 为 4:4:4；它未进入正式 cohort。数据中存在 240 个完整、shard 内、
64-vector rowgroup 对齐且全部受支持的连续 batch 候选。

| 条件 | 吞吐 p50 (img/s) | repeat min–max | 平均 batch 延迟 p50 (ms) | native rowgroups / window | native worksets / window |
| --- | ---: | ---: | ---: | ---: | ---: |
| `current_random` | 86.654 | 85.688–87.641 | 738.599 | 60,818 | 30,459 |

`paired_scattered` 和 `contiguous` 的 warmup/measured image-ID 集合分别完全相同；
前者只改变 batch 访问顺序，因此 9.13× 是主因果对照。`current_random` 完全复现当前
对 48,615 个 eligible ID 全局 shuffle 后取前 1,600 张的算法，但与连续条件不是同一
图片集合，15.60× 只作为实际迁移参考。

## 推理语义

- 同 cohort 样本数：1,280；image ID 和 labels 对齐验证均通过。
- Top-1 accuracy：打散 `64.53125%`，连续 `64.609375%`，差 `+0.078125 pp`。
- Top-5 accuracy：两者均 `85.15625%`，差 `0 pp`。
- Top-1 prediction agreement：`99.921875%`；top-5 set agreement：`99.21875%`。
- Logit max/mean absolute difference：`0.21529061 / 0.0012542644`；mean cosine
  `0.9999945870`。

不同 batch 组成会造成很小的浮点数值漂移，但本次配对样本上没有达到统计或实际显著
精度差异。

## 训练顺序探针与解释边界

探针固定 1,280 个 transformed-DCT 训练样本和另一个不重叠的 1,280-image 随机
evaluation set；两条件从同一 checkpoint 出发，使用 AdamW、`lr=1e-5`、
`weight_decay=1e-4`。连续条件每 epoch 只 shuffle 连续 batch 的顺序，打散条件每 epoch
全局 shuffle 样本。

- 三个 seed 的连续减打散 held-out top-1：`+0.234375`、`+0.078125`、
  `+0.468750 pp`；均值 `+0.260417 pp`。
- 非参数 bootstrap 95% CI `[+0.078125, +0.468750] pp`，但只有 3 个配对，精确
  sign-flip `p=0.25`；应以“未检出显著差异”解释，不能因 bootstrap CI 不跨零而过度
  声称显著。
- 连续减打散 top-5 均值为 `-0.182292 pp`，loss 均值为 `-0.0009765`。

全量训练标签结构统计覆盖 1,281,167 条 train index（20,018 个完整 batch，尾部丢弃
15 张）。它证明直接连续训练会极端降低 batch 类别混合度。推荐把物理 I/O 顺序与模型
看到的逻辑采样顺序解耦：连续读取若干 rowgroup，进入足够大的 shuffle buffer，再按
随机 sampler 组成训练 batch。
